Join a different server than the one this launcher ships with. Leave the address empty to go back to the normal server.

Staging server

A copy of the live server, used to try things out before they go live. Nothing you do there reaches the live server. It keeps its own whitelist, so you can only join once an admin has added your Steam ID to it.

Characters

Your username locks to this Steam account the first time you join with it. Only an admin can change it, through the Discord bot, and only while the server is stopped. Once one tells you yours is done, put the new name in here.

Used any earlier the server turns you away, and on an account with a spare character slot it makes a brand new character instead of moving you.

A second character needs a character slot. Staff hand those out. If you have been given one, you can make your second character here. Without one the server will turn the new name away when you press Play.

Character bodies

The server ships a replacement body model, skin textures and re-fitted clothing. Turn this off to see the vanilla ones instead. It changes only what you see, on every character in the world, and applies the next time you connect.

Cinema videos

Videos shown on the server are downloaded through the launcher. Some are copyrighted; if you opt out of those you will still see all non-copyright videos. The launcher can also download videos while your game is running. If you opt out of that, you will need to restart the game to get any added videos.

Performance mode

For frame rate trouble, especially in rain and while driving. It lowers puddle detail, water, texture size and a few effects, and leaves your resolution, frame rate cap and 3D ground items exactly as they are. Ground items stay 3D. Turning it off puts your old settings back, except for anything you have changed yourself in the game's own options since. Takes effect the next time you press Play.

Debug mode

Server admins only. The server disconnects a debug client during the join unless the account holds the built-in admin role — moderator, gm and ordinary players are all refused. Leave this off if you just want to play.

Videos on the server

We can now show videos on the server, and they are downloaded through the launcher. Some videos are going to be copyrighted, just like the songs from Lifestyle and the server's music mods are. If you don't want to have any copyrighted videos sent to you, you can opt out and you will still see all non-copyright videos.

The videos are heavily compressed, so they use very little disk space and we will be archiving older videos if they start piling up. The launcher is able to download them even when your game is running, but you can opt-out of that too if you want, and instead you will need to restart the game to download any added videos.
